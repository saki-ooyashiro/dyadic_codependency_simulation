# dyadic_codependency_simulation

## 目的

共依存と被支配を、関係全体への単一ラベルではなく、当事者ごとの有向関係として表現し、仮説モデルの挙動をシミュレーションする。

モデルは次の3層で構成する。

- **遠位層**: 個人特性(分化度・愛着不安など)
- **近位層**: 関係内状態 `(D_X, Aut_X)`, `(D_Y, Aut_Y)`
- **帰属層**: 自律性低下の主因を「本人の不安調整」または「相手の統制」として評価

## シミュレーション

Pythonで多数の仮想ダイアドを生成し、各変数を確率的に発生させる。

概念的には、

`特性 → 関係内状態 → 帰属 → エッジ分類`

という流れを再現する。

分類例:

- `X → Y`: Xの不安調整に基づく共依存エッジ
- `Y → X`: Yの統制によるXの被支配エッジ
- 双方向: 両者に異なる機序が併存

## 成果物

実行すると、主に以下を生成する。

1. **シミュレーションデータ**
   - 個人特性
   - 依存度 `D`
   - 自律性 `Aut`
   - 愛着不安
   - 統制行動
   - エッジ分類

2. **関係ネットワーク図**
   - ノード: X / Y
   - 有向エッジ: 共依存・被支配など
   - 関係の非対称性を可視化

3. **統計・分布グラフ**
   - `D` と `Aut` の関係
   - 特性分化度との関連
   - 愛着不安と統制行動の比較
   - 各エッジ分類の割合

4. **CSV**
   - 生成した仮想データを保存し、後から分析可能

## 注意

これは実証研究ではなく、**理論モデルがどのようなデータ構造を生成するかを確認するためのシミュレーション**である。

したがって、シミュレーション結果から「共依存は実際に存在する」と結論することはできない。むしろ、モデルの内部整合性、反例の発生条件、パラメータ変更による挙動を検討するために使用する。
